# Bandy Animator

En enkel webbaserad bandyanimator.

## Publicera med GitHub Pages

1. Skapa ett nytt GitHub-repository, t.ex. `bandy-animator`.
2. Ladda upp `index.html` till repositoryts rot.
3. Öppna **Settings → Pages**.
4. Under **Build and deployment**, välj **Deploy from a branch**.
5. Välj branch **main** och mappen **/(root)**.
6. Klicka **Save**.
7. GitHub visar därefter webbadressen till appen.

Appen är helt statisk och kräver ingen serverkod.
